# Security Policy

## Supported versions

The latest published RWR-API 5.x release receives security fixes. The API is a compile-time and
runtime contract; operational fixes may also require an updated ResourceWorldResetter runtime.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature for this repository. Do not open a public
issue for a vulnerability or include server logs, credentials, webhook URLs, Maven Central tokens,
signing keys, or other secrets in a public report.

Include the affected API and RWR versions, server implementation, reproduction conditions, expected
impact, and any proposed mitigation. You should receive an acknowledgement within seven days.
